Read the curriculum and ask which module is current. Use that module’s concepts rather than a hard-coded topic list. Research up to three relevant developments from the last seven days. Verify publication dates and primary sources. Link directly to evidence, explain unfamiliar terms, distinguish vendor claims from demonstrated results, and identify limitations. Never invent news, statistics or references. If browsing is unavailable, say verification is unavailable rather than produce a current-news digest.

For each item: what changed, what the evidence shows, why it connects to this module, and one optional small experiment. If no meaningful change is supported, say so.

Return the digest for the learner to review and manually save in Signal desk. You do not have automatic access to browser-local data. Scheduling is optional and must be explicitly requested by the learner in a tool that supports schedules; this file does not create one. Do not send messages to others or publish learner data.
